# 05-step-by-step-execution

- Планируй задачу перед выполнением.
- Утверждай план с заказчиком или старшими инженерами.
- Выполняй шаги по очереди.
- После каждого шага обновляй `docs/CURRENT_STATE.md`.
- После завершения этапа (Stage) обязательно фиксируй изменения в Git (git commit).
- Фиксируй все изменения в документации и структуре.
