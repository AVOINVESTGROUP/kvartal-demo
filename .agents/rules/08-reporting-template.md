# Reporting Template

После каждого шага выполнения (Execution) агент должен предоставить отчет:

1. **Files modified/created:** [Список файлов]
2. **Commands run:** [Список команд]
3. **Tests/Verification:** [Как проверено]
4. **Known Issues:** [Блокеры или баги]
5. **Next Step:** [Что делаем дальше]

Обновление `docs/CURRENT_STATE.md` обязательно.
