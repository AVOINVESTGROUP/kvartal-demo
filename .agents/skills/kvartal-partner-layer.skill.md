# Skill: KVARTAL Partner Layer

### When to Invoke
- При реализации логики назначения партнера на сделку.
- При настройке интеграций с внешними CRM партнеров.

### Deliverables
- **SLA Tracker:** Модуль контроля времени ответа партнера.
- **Partner Portal Spec:** Описание интерфейса для партнеров.

### Phase Applicability
- **Phase 1-2:** [Dormant].
- **Phase 5:** [Active] — Дубайский партнерский слой.

### Anti-Patterns
- Прямой доступ партнера к БД KVARTAL.
- Отсутствие мониторинга SLA.
