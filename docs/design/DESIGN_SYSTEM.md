## Типографика
- **Основной шрифт:** "Segoe UI", Arial, sans-serif.
- **Заголовки:** Тяжелое начертание (800-900), отрицательный кернинг (-0.045em для H1).
- **Размеры:** 
  - H1: `clamp(38px, 6vw, 68px)`
  - H2: `clamp(30px, 4vw, 46px)`
  - Lead: `20px`
  - Body: `15.5px` (1.55 line-height)

## Элементы интерфейса
- **Radius:** `18px` (основной), `12px` (формы), `999px` (кнопки).
- **Shadow:** `0 20px 60px rgba(7, 29, 58, 0.14)`.
- **Container:** `1180px`.
