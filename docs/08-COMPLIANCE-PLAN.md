# COMPLIANCE PLAN

## Цель
Документировать требования по соответствию для российского и дубайского рынков.

## Общие принципы
- Соблюдать законы RU и UAE
- Хранить данные в соответствии с PII-требованиями
- Минимизировать передачу персональных данных
- Вести журнал аудита всех критических событий

## RU
- Соответствие 152-ФЗ для персональных данных
- Хранение и обработка данных внутри допустимых регионов
- Получение согласия на маркетинг и передачу партнёрам

## UAE / Dubai
- Соблюдение Personal Data Protection Law
- DLD требования к объявлениям и рекламным материалам
- Проверка партнёров и идентификация

## Точки контроля
- Consent banner на этапе создания задачи
- Хранение токенов доступа в Secret Manager
- Логи доступа и изменений
- Регулярные ревью данных

## Документы и аудит
- Аудит логов доступа к Deal Room
- Запись всех изменений статусов
- Отчётность по GDPR-like запросам пользователей
